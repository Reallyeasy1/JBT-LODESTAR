# Acceptance Criteria Template

Write criteria as binary pass/fail checks.

## Functional Criteria
1. Given [state], when [action], then [observable result].
2. Given [state], when [action], then [observable result].
3. [Validation or error handling criterion].

## UX Criteria
1. [Required page/section renders expected data].
2. [Loading, empty, and error state behavior].

## Data / Contract Criteria
1. [Input schema validation behavior].
2. [Persistence behavior and expected fields].

## QA Criteria
1. [Manual test scenario].
2. [Regression scenario].

## Definition of Done Check
- Each criterion is testable without interpretation.
- No criterion depends on another unfinished issue.
